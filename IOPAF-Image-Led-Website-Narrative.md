# IOPAF Image-led Website Narrative

## Editorial direction

The website must feel like an executive window into the **real assessment instrument**. Authentic engine screens become the primary evidence; text explains what the reader is seeing and why it matters. Synthetic diagrams are retained only where no engine screenshot can communicate the concept more clearly.

| Website chapter | Primary authentic visual | Executive message |
| --- | --- | --- |
| Hero | Focused Controls assessment | This is a working assessment engine, not a conceptual framework. Every control is tied to target, evidence, posterior effectiveness and action. |
| End-to-end assurance | Controls Dashboard | IOPAF joins development, operations and IAM into one governed view from ideation to operation. |
| Evidence-gated assessment | Focused Controls assessment | The selected maturity level is separated from the evidence-supported effective level. |
| Target-scoped IAM | Controls Dashboard + focused assessment detail | One control is evaluated separately for enterprise, shared IAM, infrastructure, network, database, platform, cloud, application and API targets. |
| Bayesian risk | Risk Summary + Bayesian Network | Leaders receive both concise scenario interpretation and a transparent causal model with uncertainty. |
| Causal assurance | Control Interdependencies | Upstream enablers, downstream dependents and shared dependencies remain visible. |
| Decision outputs | Reports Centre + Remediation Ledger | Visual reports and target-specific action ownership carry the assessment into execution. |

## Composition system

Each screenshot sits inside a restrained **evidence frame** with a navy title rail, teal source marker, authentic-screen label and one short interpretation. Large images alternate between full-width panorama, two-image analytical spread and asymmetric image/text editorial layouts. Screens remain uncropped on mobile through contained image frames; the page may reveal less fine detail but must never fabricate a mobile version of the engine.

The hero uses the focused-assessment screenshot as a large perspective product canvas occupying more than half the first viewport. A smaller Bayesian summary window overlaps its lower edge, creating depth without obscuring essential fields. Subsequent sections use the network and interdependency images at near-full width so their real detail is visible.

## Content discipline

Copy is reduced to interpretation, not feature repetition. Every visual carries descriptive alternative text and a visible caption stating the assessment target or model context shown. The user is never led to believe that the screenshot contains their data. Example evidence is clearly presented as a product demonstration.
